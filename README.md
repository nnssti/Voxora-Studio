🎙️ Voxora StudioVoxora Studio is a powerful, open-source, offline-first video translation and AI dubbing desktop application. Engineered with a strong focus on high-quality Arabic localization, Voxora Studio offers full control over your workflows—supporting both local, privacy-focused offline engines and high-accuracy cloud APIs.✨ Key Features🌍 Arabic-First Localization: Built with full support for RTL (Right-to-Left) text formatting, Arabic numeral normalization, and natural-sounding Arabic synthetic voices.🎙️ Hybrid Dubbing Engine:Local & Offline: Process audio completely on-device using local models like whisper.cpp, Piper TTS, and Windows SAPI with zero API fees or privacy leaks.Cloud Services: Easily connect your own API keys (OpenAI, DeepL, Google Cloud Translation, etc.) for high-tier cloud performance.🎨 Subtitle & Translation Customization: Advanced subtitle styling options including custom colors, fonts, positioning, and visual tweaks.⚡ Lossless Video Processing: Powered by FFmpeg, Voxora Studio copies the original video stream whenever container specs allow—ensuring fast rendering with zero loss in video quality.🔒 Privacy & Transparency: Honest status indicators verify model files, keys, and binaries before execution. Your data stays under your control.🛠️ Supported IntegrationsFeatureSupported Engines / ServicesSpeech-to-Text (STT)whisper.cpp (Local), Custom APIsTranslationLibreTranslate (Local/Self-hosted), Argos Translate (Offline), OpenAI Chat Translation, DeepL, Google Cloud TranslationText-to-Speech (TTS)Piper TTS (Offline), Windows SAPI (Local), Cloud Voice APIs🚀 Getting StartedDownload: Grab the latest executable release from the Releases page.Import Video: Drag and drop your video file (MP4, MKV, MOV, AVI, WebM, etc.).Configure Settings: Choose your preferred translation and voice engines in the Settings menu.Generate: Click to process translation, styling, and video dubbing!📄 LicenseVoxora Studio is an open-source project released under the MIT License.
